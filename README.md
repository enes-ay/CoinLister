Coin Lister
=====
#### _This is an old repo from 2022_
This app lists the top 100 coins at CoinMarketCap. The user can track the prices, volume, supply, and add coins to favorites. The content is for informational purposes only; you should not construe any such information or other material as legal, tax, investment, financial, or other advice.

Used Technologies
=================

- MVVM
- Firebase Authentication
- CoinMarketCap API
- Retrofit
- Room
- Shared Preferences
- Live Data
- Navigation
- Viewbinding
- Coroutine
